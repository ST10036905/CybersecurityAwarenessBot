# Cybersecurity Awareness Assistant

A C# console-based chatbot to promote cybersecurity awareness and educate users about common online threats.

## Purpose

The Cybersecurity Awareness Assistant provides users with basic guidance on staying safe online through an interactive conversational experience.

## Features

* Voice greeting when the application launches
* ASCII cybersecurity logo
* Personalised user greeting
* Cybersecurity question-and-answer system
* Password safety guidance
* Phishing awareness
* Suspicious link guidance
* Safe browsing tips
* Input validation and default responses
* Coloured and formatted console interface
* GitHub version control
* GitHub Actions Continuous Integration

## Technologies

* C#
* .NET
* Visual Studio
* Git and GitHub
* GitHub Actions
* Windows Multimedia API

## Project Structure
CybersecurityAwarenessBot/

├── Program.cs

├── ConsoleUI.cs
├── ResponseHandler.cs
├── VoiceGreeting.cs
└── README.md

The application uses separate classes to improve code organisation, readability, and maintainability.

## How to Run

1. Clone the repository.
2. Open the `.sln` file in Visual Studio.
3. Ensure `voice_greeting.wav` is inside the `Audio` folder.
4. Build the solution.
5. Run the application using **Ctrl + F5**.
